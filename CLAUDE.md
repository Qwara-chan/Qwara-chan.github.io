# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio & blog for Qwara (「Qwara's Corner 🐾」) — a bilingual (中文/English) static site built with **Astro 7** + **Tailwind CSS v4**, deployed to GitHub Pages. **QWARA RESEARCH ARCHIVE design language** (NASA-Punk 档案纸 + 磁带盒未来主义 + 瑞士国际主义): 米白档案纸底、NASA 安全橙强调色、VHS 红黄青三色条、蓝图纸格/半调/胶片齿孔纹理、mono 数据读数、斜切角面板，浅色默认 + 暗色「胶片负片」双主题 —— 外加全屏播放 Hero 的解码/扫描/Glitch 动效层与隐藏的猫猫彩蛋层。

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Fetches GitHub repos, then `astro dev` (http://localhost:4321) |
| `npm run build` | `prebuild` fetches GitHub repos → `astro build` to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run check` | `astro check` — type-check only; there is **no test framework and no linter** |

Node ≥ 22.12.0. The deploy workflow (`.github/workflows/deploy.yml`) runs `npm ci && npm run build` on `master` and publishes `dist/`.

## Architecture

### Route stubs delegate to shared page components
Every route in `src/pages/` is a 2–5 line file that imports a component from `src/components/pages/` (e.g. `src/pages/blog/index.astro` → `BlogIndexPage.astro`, `src/pages/now.astro` → `NowPage.astro`). English routes live in a **mirrored `src/pages/en/` directory** — the routing is `/...` (zh, no prefix) and `/en/...` (see i18n below). When adding a route, create both the zh and the `en/` mirror; the page component itself handles `lang` via `getLangFromUrl(Astro.url)`.

### Content Layer API (no `src/content/`)
Collections are defined in `src/content.config.ts` with Zod schemas using `glob()` and `file()` loaders:
- `blog/zh` and `blog/en` — markdown/mdx posts in `src/data/blog/{zh,en}/`
- `now/zh` and `now/en` — `src/data/now/zh.mdx` / `en.mdx`
- `projects` — loaded from `src/data/projects/_github.json`

Shared query helpers live in `src/utils/posts.ts` (`getPosts`, `getProjects`, `getAllTags`, `paginate`, and the `getStaticPaths` builders `getPostStaticPaths` / `getTagStaticPaths`). Tag pages load posts in a **single collection fetch** (avoid the N+1 `getCollection()`-per-tag pattern — the grouped map is already built in `getTagStaticPaths`).

### GitHub projects auto-sync (do not hand-edit)
`scripts/fetch-github-repos.mjs` runs before every dev/build, uses `GH_TOKEN`/`GITHUB_TOKEN` when available (CI provides `GITHUB_TOKEN`), falls back to the **unauthenticated** GitHub API (60 req/hr), and writes `src/data/projects/_github.json`. That file is gitignored and regenerated at build time. On failure (rate limit/network/auth) it **keeps the previous snapshot** rather than wiping the projects page — but on a fresh clone with no snapshot it falls back to `[]` locally, or **aborts the build** in CI rather than shipping an empty projects page green. Forks and private repos are dropped.

### i18n
- `src/i18n/ui.ts` — the bilingual string dictionaries, `zh` and `en`, with `UIKey = keyof typeof ui.zh` (all UI copy must have both variants).
- `src/i18n/utils.ts` — `getLangFromUrl`, `useTranslations`, `getLocalizedPath`, `getSwitchHref` (used by the lang switcher), `formatDate`, `getWordCount` / `getReadingTime` (zh counts characters, en counts words — different WPM rates).
- Routing (in `astro.config.mjs`): default locale `zh` with **no prefix**; `en` prefixed `/en/`; fallback `en → zh`.

### Client-side scripts: re-init on View Transitions
`BaseLayout.astro` mounts `<ClientRouter />`; every interactive script on the site (StaggerGrid, Mermaid, SearchPage, PostLayout's reading-progress/TOC/copy/lightbox, the theme script) does the same thing:
```js
initX();
document.addEventListener('astro:after-swap', initX);
```
Each init tears down prior state with an `AbortController` (`prev?.abort()`) and disconnects `IntersectionObserver`s / `MutationObserver`s before re-collecting DOM — because after a swap the old DOM nodes are gone and listeners would otherwise leak. **Follow this exact pattern** when adding client JS. Theme is re-applied on `after-swap` only (mutating `before-swap` touches the outgoing document and is discarded).

### Styling: Tailwind v4, CSS-first, golden-ratio tokens
- `src/styles/global.css` imports Tailwind v4 (`@import "tailwindcss"` + `@plugin "@tailwindcss/typography"`) — **no `tailwind.config.js`**.
- The `@theme` block defines φ-based tokens which generate utilities directly: `--spacing-phi-*` → `p-phi-*`/`gap-phi-*`/`mb-phi-*`, `--text-phi-*` → `text-phi-*`, `--radius-phi-*` → `rounded-phi-*`. (v4's `aspect-*` utilities come from the `--aspect-*` namespace; `aspect-phi` is a hand-written class consuming `--ratio-phi`.)
- **Design language (NASA-Punk 档案纸)**: semantic colors are CSS custom properties in `:root` (浅色默认) / `.dark` (胶片负片) (`--bg`, `--bg-elev`, `--fg`, `--fg-muted`, `--border`, `--accent`, `--accent-soft`, plus aliases `--paper`/`--ink`/`--hairline`/`--red`/`--yellow`/`--cyan`). **Reference these vars** (`bg-[var(--bg)]`, `text-muted`, `border-default`, `text-[var(--accent)]`) rather than zinc utilities directly, so both themes stay consistent. Accent is NASA 安全橙 **`#e85d2a`** (暗色底片 `#f0833d`); text on accent surfaces uses `var(--on-accent)`.
- Archive texture utilities live in `@layer`/plain CSS: `.wall-grid`/`.schematic-grid` (blueprint 墙板拼缝), `.halftone` (dot screen), `.noise-overlay` (film grain), `.hazard-band` (diagonal caution stripes via `::after`), `.vhsbar` (red/yellow/cyan VHS 三色条, child `<i>`s), `.sprockets` (胶片齿孔), `.regmark` (印刷套准线), `.corner-marks` (HUD corner brackets), `.corner-cut` (斜切角面板, `--corner-cut`), `.stamp` (档案橡皮章), `.section-index` ("01 //" mono chips), `.readout` (mono uppercase metadata). Cards use square-ish `rounded-[4px]`/`radius-phi-sm` corners, not pills.
- Reusable component classes live in `@layer components`: `.card`, `.card-hover`, `.btn` / `.btn-primary` / `.btn-ghost` (mono, uppercase, square), `.tag-chip`, `.section-eyebrow`, `.container-px`, `.container-mx`, `.golden-section`, `.aspect-phi`. `.nav-link` active/hover state is **corner brackets**, not underline.
- Dark mode is class-based: `.dark` on `<html>`; Tailwind `@custom-variant dark` makes `dark:` work with the class. An inline boot script reads localStorage before paint; a `dark` re-apply script handles `after-swap`. **Default is light (档案纸)** — dark mode is the opt-in「胶片负片」; `.dark` is applied only when `localStorage.theme === 'dark'` (no OS-preference default).

### KaTeX & Mermaid
- **KaTeX**: `remark-math` + `rehype-katex` wired through `markdown.processor: unified({...})` in `astro.config.mjs` (Astro 7 style — top-level `remarkPlugins`/`rehypePlugins` config keys are deprecated). `$...$` / `$$...$$` work in `.md` and `.mdx`. The KaTeX CSS is imported **only** in `PostLayout.astro` (`src/styles/katex.css`) to keep it off non-post pages.
- **Mermaid**: `Mermaid.astro` (included by `PostLayout`) renders fenced ` ```mermaid ` blocks lazily — Astro 7's Shiki marks the language on `pre[data-language="mermaid"]`, **not** `code.language-mermaid`. It lazy-loads `mermaid` via dynamic `import()`, renders under `securityLevel: 'strict'`, falls back to a `.mermaid-fallback` `<pre>` on error, and re-renders on theme flip via a `MutationObserver`. Wrappers get `.mermaid-figure` class (styled in `global.css`).

### Animation system
No animation library (GSAP was removed in 2026-07 for performance). The motion language is unified around the **QWARA RESEARCH ARCHIVE "film playback" fiction** — every page is a tape being loaded, page transitions read as film being pulled through a gate, the cursor is a targeting reticle, the home hero is a fullscreen playback deck. **Easing is nonlinear only** (`--ease-out` / `--ease-out-expo` / `--ease-standard`): no bounce, no overshoot past the target (e.g. the hero name's decode "hit" uses a flash/scan line, not a spring scale).

- **Shared rAF bus — `animations/MotionBus.astro`** (mounted in `BaseLayout` before `ScrollFX`/`CursorLayer`). One `requestAnimationFrame` loop owns cursor-lerp state, smoothed scroll velocity (`--scroll-vel` on `<html>`, written only when it changes >0.05), and elapsed time. Layers needing per-frame work register a driver via `window.__motionBus.add(id, frame)` and receive state; they must **not** add their own rAF/pointer listeners. Re-created on `astro:after-swap`; consumers add a 1-frame retry for `window.__motionBus` against chunk-ordering surprises.
- **HUD cursor — `animations/CursorLayer.astro`** (mounted in `BaseLayout`). Fine-pointer-only targeting reticle (ring + dot + context label). Gated on `(pointer: fine)` and `prefers-reduced-motion`; sets `cursor-hidden` on `<html>` (`cursor: none`) only while active. Restores the native cursor during view transitions (`astro:before-swap` → remove, `astro:after-swap` → re-add) and the theme toggle (which dispatches `qw:vt-start`/`qw:vt-end`). Static `hidden` markup, no-JS safe; the driver reads the bus's already-lerped cursor position. `:focus-visible` outlines are untouched.
- **Home hero boot — `BootOverlay.astro`** (mounted in `Hero.astro`, home only). A ~3.4s cinematic QWARA TELESTATION sequence (skippable on any pointer/key): **PHASE 01 POWER** (CRT power-on — content surface expands from a high-brightness horizontal line, `boot-power` keyframes), **PHASE 02 SELF-TEST** (4 mono diagnostic lines typed out, `boot.line0..3` i18n keys), **PHASE 03 TAPE LOAD** (progress 0→100% + `HH:MM:SS:FF` 25fps frame timecode — BootOverlay owns the interval, it must NOT depend on MotionBus), **PHASE 04 SIGNAL LOCK** (5 staggered lock bars → status + skip hint), then a film-gate wipe up (orange leading edge with phosphor glow) + `qw:boot-done`. Runs only on the **first** home load: an inline pre-paint gate in `BaseLayout` adds `hero-booting` to `<html>` (which freezes `.hero-fade` via `html.hero-booting .hero-fade`), and `BootOverlay`'s script sets `sessionStorage['qwara:booted']` first so mid-boot navs / view-transition returns never replay it. Two failsafes stay in sync: BaseLayout removes `hero-booting` after **7s** if the bundle dies, and Hero's `begin()` falls back at **5.2s** (`qw:boot-done` wins when it fires first); reduced-motion and no-JS paths skip the whole thing. Overlay is fixed + `hidden` by default (zero CLS). It also renders a **cat icon** (navbar brand mark: orange `corner-cut` tile + `/avatar.png`) that is a persistent faint background stamp in the hero's bottom-right corner by default; on first load it dollies corner→upper-center during the boot and dollies back to the corner on finish — one element, one `transform` transition (`--ease-out`), so the in/out join is seamless. Center Y is set at runtime from the content block's **layout** height (`--boot-cat-offset` = `offsetHeight/2 + 75`, so the cat sits ~75px above the diagnostics) — must use `offsetHeight`, **not** `getBoundingClientRect`, because `boot-power`'s `scaleY(0.004)` squashes the content at measurement time and a transformed rect collapses the offset to the 120px floor, letting the cat sit on the text; z-index is JS-managed (`80` over the overlay → `1` after settling).
- **Hero — `Hero.astro`** (home only). Fullscreen playback deck: `wall-grid` 墙板拼缝 + 扫描线 + 扫描光带 + 旋转菱形框架（`diamond-frame`, 34s linear），斜切信号条、解码主名（乱码→成字 + 冲击横线，非线性）、左下档案数据块、底部黑色编辑台（可交互传输键 ◀◀ ■ ▶ ▶▶ 驱动解码/时间码/倒带）+ 周期 RGB Glitch（每 ~5.6s）。HeroCanvas WebGL 已移除，背景为纯 CSS/SVG 层。
- **`ScrollFX.astro`** (mounted once in `BaseLayout`, runs on every page) — the scroll choreography engine: `[data-section-reveal]` (opacity + rise wipe on enter, with `data-reveal-delay`; **no clip-path** — Chrome computes IntersectionObserver geometry from clip-path, which would break child observers), `[data-scroll-fade]` (continuous opacity/Y tied to viewport crossing, `data-scroll-fade-y`), `[data-scroll-skew]` (heading kick, `data-skew-angle`), `[data-tilt]` (cursor-follow card tilt, pointer-fine only), `[data-scroll-progress]` (per-section scaleX bar, `data-scroll-progress-target`), `[data-parallax]` (bg layers, `data-parallax-speed`). `[data-scroll-progress]` and `[data-parallax]` layout reads are **rAF-coalesced** (at most one `getBoundingClientRect` per frame; parallax drops its scroll listener when the layer leaves the viewport) so a scroll event never forces synchronous layout. VT fast path: during `data-astro-transition`, any section carrying `data-vt` **or currently in the viewport** is force-revealed (see below) so the new snapshot isn't blank. All IO + rAF based, re-inits on `astro:after-swap` with per-init `AbortController`, respects `prefers-reduced-motion`. Its own rAF loops are left untouched by the MotionBus.
- **Legacy per-component reveal** (`StaggerGrid.astro` / skill bars / timeline line) — IntersectionObserver + CSS transitions; the hidden pre-states and `.is-revealed` transitions live in `global.css`, with `prefers-reduced-motion` and a `<noscript>` override (content must never be stuck hidden without JS). `ScrollReveal.astro` was removed in the 2026-08 review cleanup — don't reintroduce it.
- Hero entrance: static furniture uses `.hero-fade` CSS keyframes (rise + fade, nonlinear — **no clip-path**: a non-composited clip wipe on the ~13rem name caused CLS + reveal paint jank, so the film-gate language lives in the root `module-in` transition and dossier panels instead); the Hero script runs the name decode, REC/timecode (string-cached — `textContent` only written when the rendered value changes), periodic glitch, and the transport deck. The brand name uses `--font-display` (Archivo Black for Latin). The scanning light band `.sweep` animates `transform: translateY` only — never `top` (a per-frame layout property).
- **Page transitions — "film load"** in `global.css`: `::view-transition-old/new(root)` are `module-out`/`module-in` (old recedes, new wipes up with a clip), a transient `[data-module-readout]` (`FILM: {NAME} // LOADING`) is shown only while `html[data-astro-transition]` is set (visible at capture time — never JS-injected), the navbar logo carries `view-transition-name: navbar-brand` and morphs across pages, and `html.theme-transition * { view-transition-name: none !important }` protects the theme toggle's circular clip reveal. Fallback path (no `startViewTransition`) fades `<body>` by opacity only — never transform (a transform on `<body>` becomes the containing block for all fixed children).
- **Shared-element morphs ("qc-" taxonomy)** — aggressive `transition:name` wiring: blog card cover/title/NOTE badge/tag chips ↔ post page (cover region added to `PostLayout`, `qc-cover-{id}` / `qc-title-{id}` / `qc-note-{id}` / `qc-tag-{id}-{tag}`; `noteHash()` in `src/utils/posts.ts` keeps the NOTE number identical), the same `BlogCard` grid morphs across home/blog/tag/search (same names on both sides), project title/stars morph card ↔ dossier (`qc-proj-{id}` / `qc-proj-stars-{id}`), tag cloud / sticky-bar chips morph into the tag page h1 (`qc-tagword-{tag}`), and the five index pages share the module-nameplate row `qc-page-head`. The home page passes `BlogCard morph={false}` to opt out of the card↔article morph there (a small home card → big article morph is low-value and costs another transition) — only the blog/tag/search listings carry the names. **Forced reveal**: during `html[data-astro-transition]`, elements carrying `data-vt`, any `[data-section-reveal]` wrapper containing one, **and any `[data-section-reveal].is-revealed`** are forced visible via CSS (opacity 1, transition none); `StaggerGrid`/`ScrollFX` immediately add `.is-revealed` in their VT fast path to sections carrying `data-vt` **or currently in the viewport** — otherwise stagger/reveal pre-states (opacity:0) would hide morph targets / page headers in the new snapshot and break the morph or flash a blank header on navigation. Name budgets are ~60 names/page max — if a page janks, drop `qc-tag-*` first. Pagination (`?page=N`) intentionally has no per-card morphs (cards change entirely; only `qc-page-head` persists). Unmatched names degrade to default crossfades. The footer RSS link carries `data-astro-reload` (same-origin XML must not go through ClientRouter).
- **CRT screen layer — `animations/CrtLayer.astro`** (mounted in `BaseLayout`, pure CSS, zero JS). Fixed overlay `z-index: 80` (above the boot overlay so the ink screen reads as CRT too, below the HUD cursor) with: scanlines (`repeating-linear-gradient`, `--crt-scan`), vignette (`--crt-vig`), a slow rolling light band (`crt-roll`, 11s **linear** — ambient exception), and a subtle whole-layer flicker (`crt-flicker`, 3.2s steps, ~1% amplitude — softened from ~2-3%: on bright paper a full-screen hard brightness cut read as a blinking bug). The layer and roll are composited (`will-change: opacity` / `transform`) so the flicker is a GPU opacity blend, not a full-viewport repaint each step. Intensity is a screen-level effect (does NOT count toward the per-surface "max 2 textures" budget) and lives in `--crt-scan/--crt-roll/--crt-vig` on `:root` (subtle) / `.dark` (slightly stronger). Static scanlines/vignette survive reduced-motion; flicker/roll are killed by the global reduced-motion block. Text effects: `.chroma` (red/cyan chromatic aberration, permanent subtle + stronger on hover for `.plate-heading`) and `.phosphor` (accent glow for mono readouts: `[data-module-readout]`, boot status, hero REC line, footer SYS chip).
- **Projects dossier narrative** (`/projects`, zh + en mirror) — `featured` repos render as full-viewport sticky dossier panels (`ProjectDossier.astro`: each `[data-panel]` runway `150vh` pins its `.narrative-panel` at `top:0` while the next slides over it). Scroll choreography lives in `ProjectsPage.astro`'s `initNarrative()`: a rAF loop writes `--panel-progress` / `--panel-reveal` (the content clip-wipe, with a `.panel-edge` leading line) per panel, drives the left-edge HUD rail (`[data-narrative-rail]`) + `0X / 0N` readout, and is skipped entirely under `prefers-reduced-motion`. Non-featured repos degrade to a `ProjectCard` wall below. Panel accent = language color via `getLanguageAccent()` in `src/utils/posts.ts`; relevant CSS lives in `global.css` under the dossier section.

## Conventions & gotchas

- **Navbar is constant-height (`h-16`); the old `h-14` scroll-shrink was broken** (h-16/h-14 coexisted and h-16 won) and "fixing" it introduced a spacer gap + a per-scroll-crossing height transition — so the scrolled state is signalled by the `[data-navbar-bg]` backdrop-blur (single blur; do NOT also toggle Tailwind `backdrop-blur-*` on the parent — that double-blurs), a `border-b`, and the hazard band. The scroll handler is rAF-coalesced and only toggles when the 20px threshold flips.
- **Content frontmatter** (blog, Zod-validated): `title`, `description`, `pubDate`, `tags`, `cover?`, `draft`, `lang`; `/now` uses `title`, `updatedDate`, `lang`. Mark a post `draft: true` to hide it — drafts are filtered in `getPosts`/`getPostStaticPaths`.
- **`dist/`, `.astro/`, and `src/data/projects/_github.json` are gitignored** — never commit them. `.astro/` holds generated type stubs.
- `sharp` is a devDependency but is required by Astro for production image optimization — keep it (0.35+ ships prebuilt binaries only; no source-build fallback on exotic platforms).
- Search (`SearchPage.astro`) is pure client-side filtering over `data-search-*` attributes with rAF-coalesced scoring — it works identically in dev and prod; no index build step.
- Blog pagination is `?page=N` (9/page) with guards against `NaN`/`0`/overflow in `BlogIndexPage.astro`.
- Blog posts use `post.id` as the slug; tag URLs must `encodeURIComponent(tag)`.
- Path aliases (in `tsconfig.json`): `@/*`, `@components/*`, `@layouts/*`, `@utils/*`, `@i18n/*`, `@styles/*`.
- Fonts are self-hosted and subset-split with `unicode-range`: HarmonyOS Sans SC (body, Latin/CJK), **Archivo Black** (拉丁展示体), **Noto Sans SC Heavy/900** (思源黑体 Heavy 档案标题, CJK 子集化到仓库实际用字), JetBrains Mono (数据读数). CJK woff2s are preloaded only for zh pages. Display headings use the `font-display` utility (`--font-display` stack). **If new CJK content is added, regenerate the Noto Sans SC Heavy CJK subset** — see the font-subset workflow in `scripts/` (pyftsubset + `--text-file` of repo-wide CJK chars).
- The cat easter-egg layer is `MeowEasterEgg.astro` — **deliberately de-emphasized (2026-08 "purity" pass) to a devtools-only reverse-cat hunt**: console kitty banner, an undocumented `window.__qwara` REPL (`help`/`flag`/`whoami`/`meowness`/`ping`), the `data-meow-rev` DOM attribute hint on the navbar avatar, and the hidden `/secret-cat/` route. It is `is:inline` and deferred via `requestIdleCallback` — don't break its idle scheduling. **Never render anything to the page** (no emoji rain / konami / typing triggers / poke / tab-away title / footer meow — all removed). When adding cat/easter-egg content, keep it console/DOM-only and keep commit messages simple (e.g. "增加了更多的猫猫") with no detailed description.
